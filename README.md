Project Title : The Beatles for Beginners

Description: This is a three page website where people can learn about the Beatles having little background on them, including their albums in order of release, some key events in their timeline as a band, and some of their iconic performances in recordings. Also, readers can quiz themselves on some common Beatles trivia.

Features: This page includes use of 
a. semantic and standard formatting HTML features
b.  in-HTML and style-sheet linked styling features
c. flexbox
d. class and id
e. links between pages
f. a table
g. an organized list
h. images and videos inserted and/or linked
i. a quiz feature usin let/if commands
